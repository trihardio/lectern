# What's new in v0.2.3

_Released 2026-11-21._

## Which file do I download?

- **Mac with Apple Silicon (M1 or newer):** `Lectern-0.2.3.dmg`. Open it and drag Lectern onto Applications.
- **Windows 10 or 11 (64-bit), preview:** `Lectern-0.2.3-windows-x64.zip`. Extract it and open `Lectern.exe`. The Windows build has not yet been tested on a real Windows PC.

## What is new

This is a small maintenance release. Nothing in the window has changed.

- **Quieter build checks.** Before each release, the finished app is started once to check that it opens. That check now runs hidden: no window and no error box appear, and the app closes by itself when its page has loaded. Before, a test copy could briefly appear on screen and sometimes showed a "Lectern could not start" message even though nothing was wrong with the app.

## The first time you open it

- **Mac:** macOS says it cannot check the app. Click Done, open System Settings > Privacy & Security, and click **Open Anyway**. Lectern is free and not registered with Apple.
- **Windows:** if SmartScreen appears, click **More info**, then **Run anyway**. Please report anything that does not work.

You need a Claude or ChatGPT plan signed in on your computer (Claude Code or Codex), or a Gemini API key. Lectern uses that sign-in or key. A Gemini key is billed by Google under your own account.

Check your download with `SHA256SUMS.txt` (`shasum -a 256 -c SHA256SUMS.txt` on a Mac).
