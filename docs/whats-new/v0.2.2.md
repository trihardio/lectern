# What's new in v0.2.2

_Released 2026-11-19._

## Which file do I download?

- **Mac with Apple Silicon (M1 or newer):** `Lectern-0.2.2.dmg`. Open it and drag Lectern onto Applications.
- **Windows 10 or 11 (64-bit), preview:** `Lectern-0.2.2-windows-x64.zip`. Extract it and open `Lectern.exe`. The Windows build has not yet been tested on a real Windows PC.

## What is new

- **Better paper search.** Lectern now plans its searches better and ranks the combined results from the databases more carefully, so more of the 25 papers it reads are ones an expert would pick. It does not find more papers overall; it picks better among them. On 57 questions that were held back during testing, expert papers among the 25 papers read rose from 14.6% to 21.2%, and answers made fewer unsupported claims. Searching now takes about 9 to 12 seconds instead of 3 to 4. This was measured with OpenAlex and Crossref only.
- **Gemini, with your own key.** If you have a Gemini API key, you can add it in Settings and use Gemini as a third engine next to Claude and ChatGPT. It stays hidden until Lectern accepts the key. It has only been tested with canned replies so far, not with a real Gemini account.
- **Writing desk:**
  - **AI writing** now marks every sentence in a green, yellow or red hatched box. Hover to see "% AI-like" or "% human-like", and click for the reason. It is labelled "not validated": it still misses a lot of AI text, especially text written to sound human, and it flags a few human texts. A score is never proof.
  - **Test bench** runs the AI check on texts you have labelled yourself (up to 30 per run) and shows how often it was right, with a range. Nothing is saved.
  - **Rewrite** has a **Style** menu with eight styles, and an optional "Match a writing sample" box that takes the voice of text you paste or upload. Rewrite does not try to get past AI detectors. A reply that used to be lost when the model put a line break in the wrong place now arrives.
  - Text copied from a PDF with line breaks is now read as whole sentences, so it is no longer cut into fragments.
- **Smoother and more even.** The sliding highlight on buttons no longer lags or jumps. Menus open upward when there is no room below. All colours now come from one base palette, and the style you pick in the cite dialog looks like every other picked choice.
- **Clearer messages.** The "no model is connected" messages now also say that a Gemini key can be added.
- **README icon:** the app icon shows on the GitHub page again.

## The first time you open it

- **Mac:** macOS says it cannot check the app. Click Done, open System Settings > Privacy & Security, and click **Open Anyway**. Lectern is free and not registered with Apple.
- **Windows:** if SmartScreen appears, click **More info**, then **Run anyway**. Please report anything that does not work.

You need a Claude or ChatGPT plan signed in on your computer (Claude Code or Codex), or a Gemini API key. Lectern uses that sign-in or key. A Gemini key is billed by Google under your own account.

Check your download with `SHA256SUMS.txt` (`shasum -a 256 -c SHA256SUMS.txt` on a Mac).
